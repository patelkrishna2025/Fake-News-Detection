About This Project

This is an AI Fake News Detection Web Application built as a final-year engineering project. It uses classical Machine Learning (TF-IDF + Logistic Regression / Passive Aggressive / Random Forest / Naive Bayes / SVM) trained entirely offline on a local dataset.

No cloud AI services, no OpenAI/Gemini/Claude/Hugging Face APIs are used anywhere — every prediction runs on a locally-trained scikit-learn model stored on disk.

Tech Stack
  • Backend: Python, Flask
  • ML: Scikit-learn, Pandas, NumPy, NLTK
  • Database: SQLite
  • Frontend: HTML, CSS, Bootstrap 5, Chart.js
