# 📰 AI Fake News Detection Web Application

An intelligent **AI-powered Fake News Detection Web Application** built with **Flask** and **Machine Learning** that accurately classifies news articles as **Real** or **Fake** using **TF-IDF Vectorization** and **scikit-learn** models. The application works **100% offline** without relying on any external AI APIs or cloud services, ensuring fast, secure, and privacy-focused predictions.

## ✨ Features

* 🤖 AI-powered Fake News Detection
* 📊 Confidence Score & Prediction Probability
* 🔍 Explainable AI with Important Keyword Analysis
* 📂 News History & Prediction Records
* 📈 Interactive Dashboard & Analytics
* 🛡️ Completely Offline (No OpenAI, Gemini, Claude, or Hugging Face APIs)
* 💾 SQLite Database Integration
* 🎨 Modern, Responsive & User-Friendly Interface

## 🛠️ Tech Stack

* **Backend:** Flask (Python)
* **Machine Learning:** Scikit-learn, TF-IDF Vectorizer
* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript
* **Database:** SQLite
* **Data Processing:** Pandas, NumPy

## 🚀 How It Works

1. Enter or paste a news article.
2. The trained Machine Learning model analyzes the content.
3. The system predicts whether the news is **Real** or **Fake**.
4. View the confidence score, prediction probability, and important keywords influencing the result.
